MASTER BRAND CREATORS — WEBSITE PACKAGE
=========================================

WHAT'S INSIDE
- index.html         Home

- services.html       Services
- portfolio.html      Portfolio

- pricing.html        Pricing
- blog.html           Blog

- 404.html            Custom 404 page
- style.css           All design system + page styles
- script.js           Lenis smooth scroll, GSAP animations, cursor, magnetic buttons, FAQ, filters, Swiper testimonials
- assets/             Empty — drop your real logo, favicon, and photography here

HOW TO USE
1. Unzip and open index.html in a browser, or upload the whole folder to GitHub Pages / any static host.
2. Replace the "MB" text mark in the navbar/footer (search for `<span class="mark">MB</span>`) with your real logo image once you send it over.
3. Swap the picsum.photos placeholder images for real project photography — search "picsum.photos" across the HTML files to find every instance.
4. Update contact details in contact.html (email, phone, address, map embed) with your real studio information.
5. All pages share style.css and script.js, so global design changes only need to be made once.

WHAT'S NEW IN THIS PREMIUM PASS

- SplitType word-by-word blur-reveal on every section heading and inner-page hero title, site-wide.

- Shimmer-sweep + ripple buttons everywhere .btn is used.
- Portfolio grid now opens a glass modal preview on click instead of jumping straight to the case study.
- Testimonial slider gained a slim autoplay progress bar.
- Contact form gained glow-on-focus fields and a shake animation on empty required fields.
- Cinematic loader now counts up 0–100% instead of just a bar.
- A slim scroll-progress line runs across the very top of every page.
- All of this lives in the same style.css / script.js so every page benefits automatically; hero-three.js and the Three.js CDN tag are only loaded on index.html.
